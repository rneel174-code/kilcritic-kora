NON-NEGOTIABLE PRINCIPLES
-------------------------
1. Simple by Default
2. Automatic by Default
3. Safe by Default
4. Human-Friendly by Default
5. Truthful by Default
6. Recoverable by Default
7. Current explicit user instruction > learned DNA/preferences
8. Safety/security/legal/platform constraints override preferences
9. High-risk external actions require approval
10. No silent production modification
11. No fake capability, result, download, publication, repair, 4K/8K, API, or web result
12. One command means one GOAL, not unlimited authority
13. Advanced power stays behind progressive disclosure
14. Safe low/medium fixes may auto-repair; high/critical changes require approval
15. Every evolution has proposal, diff, risk, tests, approval where required, verification, rollback
16. Owner preferences cannot turn false facts into true facts
17. No offensive counterattack, weaponization, destructive retaliation, or unrestricted hidden override

52. ERROR MODEL
============================================================

Every error should have:
- error_id
- task_id
- module
- category
- severity
- cause
- safe_action
- retryable
- rollback_available
- user_message
- technical_log

User message should be simple.
Technical details stay in diagnostics.
